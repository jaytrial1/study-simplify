How to Integrate

1. Add the tracker script to your page:

<script src="/main/active-users/js/tracker.js"></script>

2. Optional: Display the active user count on your page:

<script>
document.addEventListener('activeUsersUpdated', (event) => {
    const activeUserCount = event.detail.count;
    // Update your UI with the count
    document.getElementById('activeUsersCount').textContent = activeUserCount;
    document.getElementById('lastUpdated').textContent = 'Last updated: ' + new Date().toLocaleTimeString();
});
</script>

That's it! The tracker will automatically start sending pings to the server.
