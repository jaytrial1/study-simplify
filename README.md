# StudySimplify - AI-Powered Educational Platform

## 1. Overview

StudySimplify is a modern web application designed to enhance the learning experience for students. It provides an intelligent AI chatbot that helps students understand educational content, get answers to questions, and manage their study materials effectively.

Beyond individual student use, the platform also supports a **multi-tenant architecture**, allowing specific **Tuition Classes** or educational institutions to offer a personalized and branded version of the application to their own students via dedicated subdomains (e.g., `classA.studysimplify.in`).

## 2. Target Users

The platform serves several user groups:

*   **General Students:** Individual students using the main platform (`studysimplify.in`) for self-study.
*   **Tuition Class Students:** Students belonging to a partner tuition class, accessing the platform via their class-specific subdomain.
*   **Tuition Class Owners/Admins:** Individuals managing a partner tuition class, responsible for student enrollment, branding, and potentially billing within their subdomain.
*   **System Administrators:** Responsible for overall platform maintenance, owner setup, and core system management.

## 3. Core Features

### 3.1 AI-Powered Chatbot
*   **Intelligent Assistance:** Students can ask questions related to their subjects and receive detailed answers generated by an integrated AI model (like Gemini).
*   **Content Interaction:** The chatbot can access and explain content from the platform's knowledge base (stored as Markdown files).
*   **Conversation History:** Students can review past chat sessions.
*   **Answer Saving:** Important AI responses can be saved and organized for later review.

### 3.2 Multi-Tenant System for Tuition Classes
*   **Dedicated Subdomains:** Each partner tuition class gets its own subdomain (e.g., `classA.studysimplify.in`).
*   **Custom Branding:** The interface automatically adapts to show the specific tuition class's logo and color scheme when accessed via their subdomain.
*   **Separate User Flow:** Students logging in through a tuition subdomain may have a slightly different navigation path (e.g., an intermediate page offering Chatbot or Broadcast options) compared to general users.
*   **Restricted Access:** Logins are restricted, ensuring students can only access the portal associated with their registration (either the main domain or their specific tuition subdomain).
*   **(Future/Admin-Managed) Owner Dashboard:** A system exists (detailed in `4_owner_workflow.md`) for managing tuition class owners, their students, and billing/plan activation status, although the front-end dashboard for owners themselves might be a future implementation or admin-managed.

### 3.3 Content Management
*   **Hierarchical Structure:** Educational content is organized by Grade -> Subject -> Chapter -> Topic.
*   **Markdown Format:** Content is stored and read from simple Markdown (`.md`) files, making it easy to manage and update.
*   **Dynamic Navigation:** The user interface dynamically loads available subjects, chapters, and topics based on the user's grade level and selections.

### 3.4 User Management
*   **Secure Authentication:** Standard email/password signup and login.
*   **Profile Settings:** Users can manage basic profile details and change passwords.
*   **Grade Level Association:** User accounts are linked to a specific grade level, determining the content they can access.

### 3.5 Platform Features
*   **Responsive Design:** Adapts to various screen sizes (desktop, tablet, mobile).
*   **Progressive Web App (PWA):** Supports offline access for key features and can be installed like a native app on compatible devices.
