# Shah's Learning Tree Landing Page

A modern and responsive landing page for Shah's Learning Tree tuition classes.

## Features

- Responsive design that works on all devices (mobile, tablet, desktop)
- Interactive navigation with smooth scrolling
- Course showcase section
- Testimonial slider
- Contact form with validation
- Modern design with animations

## Project Structure

- `index.html` - Main HTML file containing the structure of the landing page
- `styles.css` - CSS file with all styling for the page
- `script.js` - JavaScript file with interactive functionality
- `LOGO with out BG.png` - Logo image file

## How to Run

1. Clone or download this repository
2. Open the `index.html` file in your web browser

## Customization

### To customize the content:

- Edit the text in `index.html` to update any content
- Modify contact information in the Contact section
- Update testimonials with actual student feedback

### To customize the styling:

- Edit the colors in the `:root` section of `styles.css`
- Modify fonts by changing the Google Fonts import

## Browser Compatibility

The landing page is compatible with:
- Google Chrome (latest)
- Mozilla Firefox (latest)
- Safari (latest)
- Microsoft Edge (latest)

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome for icons
- Google Fonts for typography
