# માંગ વિધેય
બે કે તેથી વધુ પરિબળો વચ્ચેના કારણ અને અસર વચ્ચેના સંબંધને વિધેય કહેવામાં આવે છે. માંગ વિધેય, વસ્તુ કે સેવાની માંગ અને તેને અસર કરતાં પરિબળોનો કાર્યકારણ સંબંધ રજૂ કરે છે. વ્યક્તિગત રીતે વસ્તુની માંગ તે વસ્તુની કિંમત, વ્યક્તિની અભિરુચિ અને પસંદગી, વ્યક્તિની આવક, સંબંધિત વસ્તુની કિંમત, વસ્તીનું પ્રમાણ વગેરે જેવાં પરિબળો ઉપર આધારિત હોય છે. વ્યક્તિની માંગનું ગાણિતિક વિધેય નીચે મુજબ છે :

$$
\begin{aligned}
& \mathrm{D}{x}=f\left(\mathrm{P}{x}, \mathrm{P}{y}, \mathrm{P}{z}, \mathrm{~T}, \mathrm{Y}, \mathrm{U}\right) \
& \text { જ્યાં, } \mathrm{D}{x}=\mathrm{X} \text { વસ્તુની માંગ (Demand for } X \text { ) } \
& f=\text { વિધેયાત્મક સંજ્ઞા (Functional Notation) } \
& \mathrm{P}{x}=\mathrm{X} \text { વસ્તુની કિંમત (Price of } X \text { ) } \
& \mathrm{P}{y}=\mathrm{Y} \text { વસ્તુની કિંમત (સંબંધિત વસ્તુની કિંમત) (Prices of Related Goods) } \
& \mathrm{P}{z}=\text { ભવિષ્યની કિંમતો અંગેની અટકળો (Expectations Regarding Future Prices) } \
& \mathrm{T}=\text { ગ્રાહકની અભિરુચિ અને પસંદગી (Consumer's Tastes and Preferences) } \
& \mathrm{Y}=\text { ગ્રાહકની આવક (Consumer's Income) } \
& \mathrm{U}=\text { અન્ય પરિબળો (Other Factors) }
\end{aligned}
$$

અર્થશાસ્ત્રમાં ઘણા હેતુઓ માટે વસ્તુની કિંમત અને તેની માંગ વચ્ચેનો સંબંધ તારવવામાં આવે છે. જેમાં કિંમત સિવાયના માંગને અસર કરતાં પરિબળો જેવા કે સંબંધિત વસ્તુની કિંમત, અપેક્ષિત કિંમત, ગ્રાહકની અભિરુચિ અને પસંદગી, વ્યક્તિની આવક અને અન્ય પરિબળોને સ્થિર ધારી લેવામાં આવે છે.
