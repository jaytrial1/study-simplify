# વ્યાપારચક્ર 
માનવજીવનની જેમ અર્થતંત્રમાં પણ ચક્રાકાર પરિવર્તનો આવ્યાં કરે છે. અર્થતંત્રમાં આવતી અસમતુલાઓ, ઊથલપાથલો, પરિવર્તનો નીચે પ્રમાણે ચાર પ્રકારના હોય છે :
(1) આકસ્મિક આર્થિક પરિવર્તનો (2) મોસમી આર્થિક પરિવર્તનો (3) દીર્ઘકાલીન આર્થિક પરિવર્તનો (4) ચક્રિય આર્થિક પરિવર્તનો.

2.9.1 આકસ્મિક આર્થિક પરિવર્તનો : અર્થતંત્રમાં અકસ્માતે જ અણધાર્યા પરિવર્તનો આવી શકે છે. દા.ત., વાવાઝોડું આવવું, અત્યંત વરસાદ અને પૂર આવવું કે દુષ્કાળ પડવો. આવાં આકસ્મિક પરિબળો અર્થતંત્રમાં મોટી ઊથલપાથલ કે લાંબા ગાળાની અસરો સર્જે છે.
આકસ્મિક પરિવર્તનો ઘણી વાર અર્થતંત્રના કોઈ એક ભાગ કે પ્રદેશ પૂરતા પણ મર્યાદિત હોઈ શકે. દા.ત., ખેતી, ઉદ્યોગક્ષેત્ર.

2.9.2 મોસમી આર્થિક પરિવર્તનો : અર્થતંત્રમાં ઋતુ આધારિત પરિવર્તનો પણ આવે છે. શિયાળામાં, ઉનાળામાં, ચોમાસામાં બજારમાં જુદી જુદી માંગ સર્જાતી હોય છે અને તે મુજબ ઉત્પાદન-રોજગારીમાં પણ પરિવર્તનો આવે છે. જેમકે, દર વર્ષે મોસમી પરિવર્તનનું એક ચક્ર ચાલ્યા કરે છે અને તેમાં સમયાંતરે પરિવર્તન આવ્યા કરે છે.

2.9.3 દીર્ઘકાલીન આર્થિક પરિવર્તનો : અર્થતંત્રમાં કોઈ ચોક્કસ દિશામાં લાંબા સમય સુધી પરિવર્તનની પ્રક્રિયા ચાલે છે તેને દીર્ઘકાલીન આર્થિક પરિવર્તનો કહે છે.
કોઈ પણ ગતિશીલ અર્થતંત્રમાં લાંબા ગાળાનાં પરિવર્તનો આવતાં જ હોય છે. જે એક જ દિશામાં હોય છે. અહીં પરિવર્તનો ચક્રાકાર હોતાં નથી.

2.9.4 ચક્રિય આર્થિક પરિવર્તનો : એક સમયગાળા દરમિયાન ઊર્ધ્વગામી અને અધોગામી આર્થિક વલણો સર્જાય તે ચક્રીય આર્થિક પરિવર્તનો છે અને આવાં પરિવર્તનો નિશ્ચિત ન હોવા છતાં ઓળખી શકાય તેવાં હોય છે. વ્યાપારચક્રો આવાં ચક્રીય પરિવર્તનો હોય છે. જુદા જુદા અર્થશાસ્ત્રીઓએ વ્યાપારચક્રની વ્યાખ્યા આપી છે.
