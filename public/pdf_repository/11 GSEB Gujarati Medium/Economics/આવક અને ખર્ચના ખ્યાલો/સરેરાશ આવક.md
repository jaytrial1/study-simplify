# સરેરાશ આવક
કોઈ એક પેઢીની સરેરાશ આવક તે પેઢીની કુલ આવકને પેઢીના કુલ ઉત્પાદન (વેચાણ) એકમોથી ભાગવાથી મળે છે. એટલે કે,
સરેરાશ આવક $=\frac{\text { કુલ } \text { આવક }}{\text { કુલ વેચાણ }}$
$$
\mathrm{AR}=\frac{\mathrm{TR}}{\mathrm{Q}} \quad \text { જેમાં, } \quad \mathrm{AR}=\text { સરેરાશ આવક }
$$
$$
\begin{aligned}
\mathrm{TR}  =\text { કુલ } \text { આવક } \\
\mathrm{Q}  =\text { વેચાણ થતી વસ્તુના એકમો }
\end{aligned}
$$
ઉદાહરણ દ્વારા સમજીએ. પેઢીએ પેનનું વેચાણ 1000 એકમોનું કર્યું છે અને પેઢીની કુલ વેચાણ-આવક ₹ 50,000 છે. સૂત્ર પ્રમાણે મૂકીએ તો, $\frac{50000}{1000}=\text{₹ } 50$ એ સરેરાશ આવક છે. એટલે કે પેનના એક એકમદીઠ થતી આવક એ સરેરાશ આવક છે. સામાન્ય રીતે પેઢી બધા એકમોનું વેચાણ એકસરખી કિંમતે કરે છે તો સરેરાશ આવક કિંમત જેટલી હોય છે. એવું માની લેવામાં આવે છે. જો કિંમત અને સરેરાશ આવક સરખા હોય તો ઉત્પાદક માટેની તેની વસ્તુની માંગરેખા એ જ એના માટે સરેરાશ આવકની રેખા છે. માંગરેખા જુદી જુદી કિંમતે ગ્રાહકો વસ્તુના કેટલા એકમો ખરીદવા તૈયાર છે તે બતાવે છે, જ્યારે સરેરાશ આવક-રેખા વસ્તુના વેચાણના જુદા જુદા પ્રમાણ સાથે સંકળાયેલી સરેરાશ આવક દર્શાવે છે. આપણે એ યાદ રાખવું જોઈએ કે, ઉત્પાદકની દૃષ્ટિએ જે સરેરાશ આવક છે તે જ ગ્રાહકની દૃષ્ટિએ કિંમત છે.
