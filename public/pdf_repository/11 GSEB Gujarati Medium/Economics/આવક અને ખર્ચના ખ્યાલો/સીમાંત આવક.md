# સીમાંત આવક
પેઢીની સરેરાશ આવક એ વસ્તુની એકમદીઠ વેચાણ-આવક છે. જ્યારે સીમાંત આવક વસ્તુના વધારાના એકમનું વેચાણ કરીને મેળવવામાં આવતી આવક છે. વસ્તુના વધારાના એક એકમના વેચાણના પરિણામે પેઢીની કુલ વેચાણ-આવકમાં જે વધારો થાય છે તેને સીમાંત આવક કહેવામાં આવે છે. એક ઉદાહરણ દ્વારા સમજીએ. પેઢી 1000 પેનનું વેચાણ કરીને ₹ 50,000 મેળવતી હોય. હવે પેઢી 1001મા પેનના એકમનું વેચાણ કરે છે અને પેઢીની કુલ આવક ₹ 50,045 થાય છે, તો પેઢીની આવકમાં જે ₹ 45નો વધારો થયો તે સીમાંત આવક છે. આમ, વસ્તુના વધારાના એકમના વેચાણથી પેઢીની આવકમાં જે વધારો થયો છે તે સીમાંત આવક છે. સૂત્ર અથવા સમીકરણમાં સીમાંત આવકને નીચે મુજબ મૂકી શકાય :
$$
\begin{aligned}
 \mathrm{MR}_{n}=\mathrm{R}_{n}-\mathrm{R}_{(n-1)} \\
 \text { જ્યાં, } \mathrm{MR}=\text { સીમાંત આવક } \\
 n=\text { વેચાણ એકમોની સંખ્યા } \\
 \mathrm{R}_{n}=n \text { એકમોના વેચાણથી થતી આવક } \\
 \mathrm{R}_{(n-1)}=(n-1) \text { એકમોના વેચાણથી થતી આવક }
\end{aligned}
$$

આગળ જણાવેલા ઉદાહરણમાં ઉત્પાદક અથવા વેચનાર પેનના 1000 એકમો ₹ 50ની એકમ દીઠ કિંમતે વેચે છે ત્યારે કુલ આવક ₹ 50,000 થાય છે. હવે પેનના 1001 એકમ વેચવાથી તેની કુલ આવક ₹ 50,045 થાય, તો સીમાંત આવક સૂત્ર દ્વારા નીચે મુજબ મેળવી શકાય :

$$
\begin{aligned}
\text{અહીં } n  =1001 \text { અને } \\
\text{તેથી } (n-1)  =1000 \\
\mathrm{MR}_{n}  =\mathrm{R}_{n}-\mathrm{R}_{(n-1)} \\
 =50,045-50,000 \\
 =\text { ₹ } 45 \text { એ સીમાંત આવક છે. }
\end{aligned}
$$
