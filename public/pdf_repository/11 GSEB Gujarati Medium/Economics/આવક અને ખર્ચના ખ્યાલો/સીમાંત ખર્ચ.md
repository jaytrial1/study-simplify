# સીમાંત ખર્ચ
અર્થ : આપણે જાણીએ છીએ કે, ઉત્પાદન વધારવામાં આવતા ખર્ચમાં પણ વધારો થાય છે. કુલ ઉત્પાદનમાં એક એકમનો વધારો અથવા ઘટાડો થવાથી કુલ ઉત્પાદન-ખર્ચમાં જે ફેરફાર થાય તેને સીમાંત ખર્ચ કહે છે. ટૂંકમાં, વધારાનું એક એકમ ઉત્પન્ન કરવાથી કુલ ખર્ચમાં થતો ફેરફાર એ સીમાંત ખર્ચ છે.
સૂત્ર અને ઉદાહરણ : આપણે n એકમોના ઉત્પાદન-ખર્ચ અને (n-1) એકમોના ઉત્પાદન-ખર્ચના તફાવત દ્વારા સીમાંત ખર્ચ (MC) મેળવવા સંજ્ઞાની રીતે નીચે મુજબ સૂત્ર દર્શાવી શકીએ :

$$
\begin{aligned}
\mathrm{MC}_{n} =\mathrm{TC}_{n}-\mathrm{TC}_{(n-1)} \\
n  =\text { એકમોની સંખ્યા } \\
\mathrm{MC}_{n}  =n \text { એકમનો સીમાંત ખર્ચ } \\
\mathrm{TC}_{n}  =n \text { એકમનો કુલ ખર્ચ } \\
\mathrm{TC}_{(n-1)}  =(n-1) \text { એકમનો કુલ ખર્ચ } \\
\text{સૂત્રમાં } n  =3 \text { મૂકતાં } \\
\mathrm{MC}_{3}  =\mathrm{TC}_{3}-\mathrm{TC}_{(3-1)} \\
 =\mathrm{TC}_{3}-\mathrm{TC}_{2} \\
\text { જ્યાં } \mathrm{TC}_{3}  =21 \text { અને } \mathrm{TC}_{2}=16 \text { તેથી } \\
\mathrm{MC}_{3} = 21-16 \\
 =5 \text { સીમાંત ખર્ચ છે. }
\end{aligned}
$$

નીચેની અનુસૂચિ મુજબ, ત્રીજા એકમનો સીમાંત ખર્ચ એ ત્રીજા એકમના કુલ ખર્ચ (TC3) અને બીજા એકમના કુલ ખર્ચ (TC2) ના તફાવત જેટલો, એટલે કે 5 (પાંચ) છે.
યાદ રાખવું જોઈએ કે, સીમાંત ખર્ચ સ્થિર ખર્ચથી સ્વતંત્ર હોય છે. તેથી કહી શકાય કે સીમાંત ખર્ચ એ અસ્થિર ખર્ચમાં થતા ફેરફારનું પરિણામ છે. જ્યારે ઉત્પાદન (n-1) એકમો પરથી વધીને n એકમો થાય છે, ત્યારે કુલ અસ્થિર ખર્ચમાં થતા વધારા જેટલો સીમાંત ખર્ચ હોય છે. સીમાંત ખર્ચ ઉત્પાદનમાં ફેરફાર થવાથી કુલ ખર્ચમાં થતા ફેરફાર બરાબર હોય છે.
અનુસૂચિ :
| ઉત્પાદનનું પ્રમાણ (TP) (એકમમાં) | કુલ ખર્ચ (TC) (₹ માં) | સીમાંત ખર્ચ (MC) (₹ માં) |
| :--: | :--: | :--: |
| 1 | 9 | 9 |
| 2 | 16 | 7 |
| 3 | 21 | 5 |
| 4 | 28 | 7 |
| 5 | 40 | 12 |
| 6 | 54 | 14 |
| 7 | 70 | 16 |
અનુસૂચિમાં દર્શાવ્યા મુજબ ત્રીજા એકમ સુધી ઉત્પાદન વધતા સીમાંત ખર્ચ ઘટે છે. ત્રીજા એકમે સીમાંત ખર્ચ લઘુતમ (₹ 5) છે, ત્યાર પછી સીમાંત ખર્ચમાં સતત વધારો થતો જાય છે. આ વલણો પૃષ્ઠ 55 પરની આકૃતિમાં જોઈ શકાય છે.
(સુધારેલ) 5.3.7 સીમાંત ખર્ચની આકૃતિ
આકૃતિમાં દર્શાવ્યા મુજબ, કુલ સરેરાશ ખર્ચની જેમ જ, શરૂઆતમાં સીમાંત ખર્ચ ઘટે છે, પરંતુ અમુક સમય બાદ તેમાં વધારો થાય છે. કારણ કે ઉત્પાદન વધતા આરંભમાં કુલ અસ્થિર ખર્ચ ઘટતા દરે વધે છે અને અમુક બિંદુ પછી વધતા દરે વધે છે. તેથી શરૂઆતમાં ઉત્પાદન વધતા સીમાંત ખર્ચ ઘટે છે અને અમુક બિંદુ પછી વધે છે. આકૃતિમાં સીમાંત ખર્ચની રેખા ‘U’ આકારની (અથવા હૉકી સ્ટિક જેવી) હોય છે. ત્રીજા એકમ સુધી સીમાંત ખર્ચ ઘટે છે. તેથી સીમાંત ખર્ચની રેખા (શરૂઆતમાં) ઋણ ઢાળવાળી છે. ત્રીજા એકમ પછી ઉત્પાદન વધતા સીમાંત ખર્ચ વધે છે. પરિણામે સીમાંત ખર્ચની રેખા ધન ઢાળવાળી બને છે.
