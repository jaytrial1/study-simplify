This section presents the linear equations for the Consumption Function and the Saving Function and explains how they are derived.

# Equation of Consumption Function

The Consumption Function can be understood in two parts:
(i) **Autonomous Consumption (c̄):** The minimum consumption level when income (Y) is zero. This is always positive.
(ii) **Induced Consumption (bY):** The portion of consumption that changes with income. This is determined by the Marginal Propensity to Consume (b or MPC) multiplied by the income level (Y). The MPC (b) shows how consumption changes with changes in income.

So, the linear Consumption Function can be represented as:
**C = c̄ + b(Y)**
Where:
*   C = Consumption
*   c̄ = Autonomous Consumption (intercept on the Y-axis)
*   b = MPC (slope of the consumption function)
*   Y = Income

Autonomous consumption expenditure (c̄) is not influenced by income, while induced consumption (bY) is the consumption expenditure that changes with a change in income.

The equation C = c̄ + b(Y) is the equation of a straight line, where 'c̄' is the intercept and 'b' is the slope. A higher value of 'b' means a steeper slope of the linear consumption function.

This equation can be used to calculate consumption for different income levels if autonomous consumption and MPC are known. For example, if c̄ = ₹40 crores and b = 0.80, then consumption (C) at an income of ₹100 crores will be:
C = 40 + 0.80(100) = 40 + 80 = ₹120 crores.

## Equation of Saving Function

The equation of the linear saving function can be derived from the equation of the linear consumption function.
We know:
(1) S = Y - C
And the consumption function is:
(2) C = c̄ + b(Y)

Substituting the value of C from (2) into (1):
S = Y - [c̄ + b(Y)]
S = Y - c̄ - bY
**S = -c̄ + (1-b)Y**
Where:
*   S = Saving
*   -c̄ = The amount of negative saving (dissaving) at zero income level (intercept on the Y-axis)
*   (1-b) = MPS (since MPC + MPS = 1, so MPS = 1 - MPC). This is the slope of the saving function.
*   Y = Income

The equation S = -c̄ + (1-b)Y is the equation of a straight line, where '-c̄' is the intercept and '(1-b)' is the slope.

This equation can be used to calculate saving for different income levels if autonomous consumption and MPS are known. For example, if c̄ = ₹40 crores (so -c̄ = -₹40 crores) and MPS = 1-b = 0.20, then saving (S) at an income of ₹100 crores will be:
S = -40 + 0.20(100) = -40 + 20 = -₹20 crores.
