# Summary of Important Formulas

Here are the key formulas discussed in this chapter:

| Concept | Formula |
| :-- | :-- |
| **Multiplier (k)** | $k = \frac{\Delta Y}{\Delta I} = \frac{1}{1-MPC} = \frac{1}{MPS}$ |
| **Aggregate Demand (AD) (Two-Sector Model)** | $AD = C + I$ |
| **Aggregate Supply (AS) (Identity)** | $Y = C + S$ |
| **Equilibrium Condition (AD-AS Approach)** | $AD = AS$ |
| **Equilibrium Condition (S-I Approach)** | $S = I$ |
| **Consumption Function** | $C = \bar{c} + b(Y)$ <br> (where $\bar{c}$ is Autonomous Consumption, $b$ is MPC) |
| **Saving Function** | $S = -\bar{c} + (1-b)Y$ <br> (where $-\bar{c}$ is Autonomous Saving, $(1-b)$ is MPS) |
| **Aggregate Demand Function (under Fixed Price)** | $AD = \bar{A} + b(Y)$ <br> (where $\bar{A}$ is Total Autonomous Expenditure) |
| **Total Autonomous Expenditure ($\bar{A}$)** | $\bar{A} = \bar{c} + \bar{I}$ <br> (where $\bar{I}$ is Autonomous Investment) |
| **Equilibrium Income (Y) (under Fixed Price)** | $Y = \frac{\bar{A}}{1-b}$ |

( $\bar{c}$ = Autonomous Consumption; $b$ = MPC; and $(1-b)$ = MPS )
