# Feedback and Continuous Nature of Controlling

The controlling function doesn't end with implementing corrective action. A key object of any control system is to provide required information through **feedback** so that future deviations can be corrected. A feedback report lists reasons for deviations and corrective measures taken. This report serves as a base for establishing future standards. This is why controlling is called a **Continuous Process**.
