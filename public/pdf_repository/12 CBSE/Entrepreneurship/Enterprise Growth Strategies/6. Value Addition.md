This section defines value addition in business, explains how it transforms commodities into branded products, and describes different types of added value.

# Value Addition

Businesses add value to goods and services by modifying them to create a new product of greater value to customers.

*   **Financial View**: Added value is the difference between the value of inputs used in production and the value of outputs.
*   **Marketing View**: Adding value turns a commodity into a branded product. Value can also be added by enhancing design, characteristics, or features of branded products/services.

**Commodities** are unprocessed raw products (crude oil, fresh fruit). To add value, they are processed into branded products consumers pay more for. Example: Turning milk (commodity) into packaged cheese (branded product with added value).

Value people place on goods/services determines quantitative value (price) and qualitative value (desirability).

## Common Examples of Adding Value

*   Turning cotton into fabric
*   Turning milk into cheese
*   Packaging ready-to-use grated cheese into serving size packets
*   Turning wood into paper
*   Designing a mobile phone that can also take photographs
*   Fortifying food with vitamins and minerals

## Types of Added Value

Businesses can employ several types of added value:

*   **Quality Added Value**: Adding convenience, ease of use, or other desirable characteristics (e.g., pull tabs, sipper tops).
*   **Environmental Added Value**: Using methods less harmful to the environment (e.g., using less energy, recycled packaging).
*   **Cause-Related Added Value**: Contributing part of revenue from a product/service to a social cause (e.g., donating a percentage to charity).
*   **Cultural Added Value**: Employing production methods or systems that respect cultural aspects or needs of ethnic groups (e.g., producing kosher food, using bilingual communication).

These types are not mutually exclusive and can be used at any phase of the production or service cycle. Adding value can be a marketing strategy to differentiate products and should be included in business plans.
