# DIFFERENCE BETWEEN COMMUNICATION AND REPORTING

| Communication | Reporting |
| :--: | :--: |
| (1) It includes sending and receiving information both. | (1) It implies giving information only. |
| (2) It is a two-way process. | (2) It is a one-way process. |
| (3) It is the most important function of management. | (3) Reporting is less important as compared to communication. |
| (4) Communication is a psychological function. It requires an understanding of the ideas of the other persons. | (4) Since reporting is a one-way process, it is not a psychological function. |
| (5) In communication, all sorts of tools are used such as oral, verbal, visual etc. | (5) Reporting is generally verbal or written only. |
| (6) It includes clarification of information, construction of message, transmission, interpretation, follow-up etc. | (6) Reporting includes preparation, and receiving of reports, deliberation and decisions of them. |
| (7) Communication includes reporting also. | (7) Reporting does not include complete communication. |
