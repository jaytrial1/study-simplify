# INTRODUCTION
Control is an important function of management because it ensures that everything is being done as planned, as per instructions given and as per established principles. Certain techniques are used to make the control function more effective. They are two type of control techniques :
(1) Traditional Methods (2) Modern Methods
(A) Traditional Methods :
(1) Budgetary Control (2) Break Even Analysis (3) External and Internal Audit (4) Control Points
(B) Modern Methods :
(1) PERT (2) CPM (3) Zero-based Budgeting (ZBB) (4) Electronic Data Processing and Computer
We discuss the control techniques prescribed in the syllabus.
