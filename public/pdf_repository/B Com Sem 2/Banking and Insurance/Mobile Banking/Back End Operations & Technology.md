Back End Operations & Technology

# Core Concepts

-   **Servers & Infrastructure:** The hardware and network systems that host the mobile banking platform.
-   **Databases:** Securely store customer account information, transaction history, etc.
-   **Security Measures:** Firewalls, encryption, intrusion detection systems, secure coding practices.
-   **Integration with Banking Systems:** Connecting the mobile platform to the bank's core banking system for real-time data processing.

# How it Works (Frontend/Backend Interaction)

-   The mobile backend runs on a remote server and communicates with the mobile app (frontend) to deliver features to end-users.
-   The mobile app backend server performs remote tasks and processes information to make the frontend app experience better.
-   When a user taps on the screen (frontend interaction), the frontend sends a request to the backend.
-   The backend retrieves the information required to perform a function via an API (Application Programming Interface) and sends back the final output to the frontend, which is then displayed to the user.

# Key Technologies

-   **API (Application Programming Interface):** Enables communication between the mobile app and the backend server, and potentially third-party services.
-   **Cloud Computing:** Provides scalable and flexible infrastructure for hosting backend services.
-   **Biometric Authentication:** Technologies like fingerprint or facial recognition for secure login.
-   **AI & ML (Artificial Intelligence & Machine Learning):** Used for fraud detection, personalized recommendations, chatbots, and risk assessment.
