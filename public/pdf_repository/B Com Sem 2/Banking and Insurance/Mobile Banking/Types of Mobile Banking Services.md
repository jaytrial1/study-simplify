Types of Mobile Banking Services

# Mobile Banking over SMS (SMS Banking)

-   Banking information through SMS.
-   This was one of the earliest forms, allowing basic functions like balance checks via text messages.

# USSD (Unstructured Supplementary Service Data) Based Mobile Banking

-   USSD allows mobile banking transactions using a basic feature mobile phone.
-   There is no need to have mobile internet data.

## USSD - \*99# Service

-   Banking customers can avail this service by dialing `*99#`.
-   The transaction is secured by MMID (Mobile Money Identifier) & MPIN (Mobile PIN).

## How to Get USSD Service

1.  Provide KYC (Know Your Customer) information to open a new account.
2.  Mobile no. should be linked with the bank a/c.
3.  Register for USSD/Mobile Banking.
4.  Get MMID (Mobile Money Identifier).
5.  Get MPIN (Mobile PIN).
6.  Service Activation.

## Transferring Money using USSD

Services available via USSD (`*99#`):

**Financial Services:**

-   Sending Money using Mobile No
-   Sending Money using UPI ID
-   Sending Money using Aadhaar No.
-   Sending Money using Account No. - IFSC
-   Requesting Money using UPI ID / Mobile No.

**Non-Financial Services:**

-   Account Balance
-   Set UPI PIN
-   Change UPI PIN
-   Last 5 transactions

**Value Added Services:**

-   Aadhaar linking Status
-   PMJDY A/C Overdraft Status

# Mobile Banking over Mobile Applications

-   For Smartphones and Android devices.
-   The mobile banking application is very user-friendly and convenient to use.
-   This gives customers the freedom to take benefit of banking services using their mobile phone.
-   There are several mobile banking applications wherein an account holder can have mobile-based conversations with the bank representative in case of any query or doubts.

# Mobile Wallets

-   Applications that store payment card information and allow users to make payments electronically. (Often integrated within or alongside mobile banking apps).
