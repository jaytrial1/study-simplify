This section briefly explains the nature of costs in the long run and how the long-run average cost curve is derived.

# Long Run Average Cost Curve

According to Benham, in the long run, there is no distinction between fixed cost and variable cost. All factors of production are variable in the long run, making the classification of costs as fixed and variable irrelevant. To increase production in the long run, firms can alter factors of production in any proportion and expand their scale. For example, while employee remuneration might be a fixed cost in the short run, in the long run, a producer can hire new workers, buy new land, or rent more space in response to increased demand. Thus, factors that are fixed in the short run become variable in the long run. The Long Run Average Cost (LRAC) curve is derived from the short-run average cost curves for different possible plant sizes.
