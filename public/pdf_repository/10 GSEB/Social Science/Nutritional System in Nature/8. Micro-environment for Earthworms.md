# Micro-environment for Earthworms

A specific micro-environment is required for earthworm activity to continue. If this environment is absent, earthworms go into hibernation. They become active again when this special situation is recreated.

## Micro-environment Definition

> **Question:** What is a micro-environment?
> **Answer:** A micro-environment is a specific unitary state defined by the air flowing between any two plants above the soil surface. It requires a daytime temperature of 24°C to 32°C and a relative humidity of 65% to 72%. This environment is created using elements like *jivamrit*, *Ghanjivamrit*, and a soil crust (*aachhadan*).
